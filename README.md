Stoxly is a full-stack fintech web app that lets users track a personalized watchlist of stocks and crypto assets, see live market movements (top gainers/losers, index performance), and get AI-generated summaries of what happened in their portfolio and why — powered by the Claude API and streamed in real time. It includes full auth (email + Google OAuth, JWT sessions), a MongoDB-backed data layer, and price alerts. Built to demonstrate real-time data handling, third-party API integration, AI streaming, and full-stack auth — not just CRUD.
